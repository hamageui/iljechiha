# 일제치하 (日帝治下)

일제강점기(1910~1945) 경성·평양·부산을 배경으로 한 텍스트 RPG.

- 플레이: https://hamageui.github.io/iljechiha/
- made by 하마귀

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 게임 페이지 (`build.py` 로 만든다 — 직접 고치지 않는다) |
| `data/` | 게임 데이터 복사본 (`build.py` 로 만든다) |
| `src/Main.logic.html` | 화면과 진행 코드 원본 |
| `src/*.js` | 게임 데이터 원본 (사건·전투·도시 등) |
| `img/` | 제목 글씨, 배경 그림 |
| `support.js` | 화면을 그리는 실행 파일 |

## 고치고 올리기

1. `src/` 안의 파일을 고친다.
2. `python build.py` 를 실행한다.
3. 바뀐 파일을 모두 커밋하고 푸시한다. 1~2분 뒤 사이트에 반영된다.

저장은 브라우저(localStorage)에 3칸까지 자동으로 된다. 사이트 주소가 바뀌면 저장도 따로다.
